COMPILAR EL PROYECTO:
    php -S localhost:8000 -t Publico

COMPILAR LA BASE DE DATOS:
    sudo mysql < baseDatos1.sql

COMPROBAR QUE SE COMPILO CORRECTAMENTE(BASE DE DATOS):
    sudo mysql

VER TABLAS:
    SHOW DATABASES;
    USE baseDatos1;
    SHOW TABLES;

CREAR USUARIO CON PRIVILEGIOS EN MYSQL:
    GRANT ALL PRIVILEGES ON *.* TO 'key'@'localhost' WITH GRANT OPTION;
    FLUSH PRIVILEGES;

LEVANTAR APACHE Y MARIA DB
    sudo systemctl start apache2
    sudo systemctl start mariadb

NAVEGADOR
    http://localhost/phpmyadmin
